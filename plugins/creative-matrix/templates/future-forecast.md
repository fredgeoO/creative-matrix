# 怎么用

先不要问“未来会怎样”，而是问“如果这三件事同时发生，什么会变得稀缺、什么会变得便宜、什么会变得不可逆”。

每个交叉点都要求写出：一条趋势、一条反例、一个可以提前做的小动作。最后把所有格子里的“小动作”按可逆性排序，先做那些做错了也不致命的事。

# 提示

这张表不是预言机。它的价值在于让你提前准备，而不是让你显得聪明。

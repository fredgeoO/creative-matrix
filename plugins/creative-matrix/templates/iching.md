# 怎么用

纵横两轴是八卦：纵轴一卦为外（上），横轴一卦为内（下），每一格就是两卦相叠所得的那一别卦——由插件调模型推演生成，模板本身不预填六十四卦。生成时先让模型报出卦名（如乾上坤下即否、坤上乾下即泰），再谈这一处境里的经文要义。

每格最后要落到一个具体动作，比如「这周先停止追加投入」「先找一个人把话说开」。没有动作的卦象解读，只是故事。对角线是纯卦（如乾上乾下），写的是这种力量自我强化时的走向与解法。

# 提示

《易经》在这里是换视角的工具。模型偶尔会把上下卦叠错或记错卦名，载入后可抽查几格核对卦名是否正确。涉及医疗、法律、重大财务的决定，请找相应领域的专业人士。

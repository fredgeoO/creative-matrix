# 怎么用

选一个你正在做的判断，让每一个学科都来“挑刺”：复利视角说它太慢，概率视角说它赔率不够，激励视角说别人会反着来……

同一个判断如果能在六个视角下都站住，它大概率不是一个只靠情绪撑着的决定。

# 提示

格栅不是让你变成什么都懂一点的人，而是让你在关键时刻多几个可以换的镜头。

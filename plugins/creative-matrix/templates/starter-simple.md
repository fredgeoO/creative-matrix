# 怎么用

先挑一个普通东西（比如苹果），再挑一个普通场景（比如下雨天），问自己：如果苹果是这场雨里唯一的食物，会发生什么？

不用追求“高级”，重点是每一步都能说出因果：因为水会结冰，所以……；因为影子跟着人动，所以……。把这个理由讲给一个十岁的小孩听，他听懂了，这个点子就成立。

# 提示

- 一次只推演一个交叉点，别急着填满整张表。
- 生成后把最有趣的一句抄下来，下次从这句继续往下想。
- 这张表本身就是一份可以反复玩的创意作业。

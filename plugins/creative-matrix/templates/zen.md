# 怎么用

不要急着“解决”情绪，先把它描述清楚：身体哪里紧、脑子里在重复哪句话、这句话预设了什么。

每个格子的目标不是给出一句鸡汤，而是给一个今天就能做的小练习，比如“洗碗时只洗碗，走神了就回来一次”。

# 提示

禅宗视角适合松开执着，不适合替代心理或医疗支持。如果困扰持续影响生活，请寻求专业帮助。
